# Leatherworking recipe sources

The tracker includes all 592 recipe spells in the November 20, 2026 ForeverDB Leatherworking catalog for client build **1.60.1.70959**. It preserves alternate spells with the same recipe name, camping crafts, and legacy client entries. Open **Professions → Leatherworking**, or append `#profession=Leatherworking` to the tracker URL. [ForeverDB Leatherworking catalog](https://foreverdb.net/profession/leatherworking) · [Client data](https://foreverdb.net/data/professions/leatherworking.json)

Ingredient quantities and output yields are per craft. The client records the yellow and grey thresholds. Green uses the Classic convention of rounding their midpoint down. Orange starts at the known learning skill when that skill is below yellow. Equal thresholds skip the earlier color. Some trainer learning requirements come from Classic and are labeled on the page. Recipes with an unknown learning skill are excluded while the skill filter is active. [ForeverDB skill-up method](https://foreverdb.net/profession/leatherworking/leveling)

Acquisition details combine the catalog's trainer listings, ForeverDB's player-observed drop, vendor and quest records, and Merchant’s Favor vendor inventories. Classic records and supplemental Playfulls community references are labeled. When a source identifies only the method or the reputation requirement, the page shows the available details. The Sewing Machine blueprint's drop from Vectus comes from Wowhead Forever's loot data. [ForeverDB data provenance](https://foreverdb.net/developers) · [Merchant’s Favor vendor data](https://foreverdb.net/data/favor.json) · [Playfulls recipe sources](https://playfulls.com/professions/leatherworking/recipes) · [Blueprint: Sewing Machine](https://www.wowhead.com/forever/item=273121/blueprint-sewing-machine)

The snapshot has 110 entries with no documented acquisition method. Some other entries have only Classic or community acquisition references. The table flags unverified Forever availability. Three reagent IDs in legacy client entries have no resolved name in the inspected records. Winter Boots has a documented learning skill of 285 and no published color thresholds in the catalog. [Pattern: Winter Boots](https://foreverdiff.com/items/pattern-winter-boots-34262/)

The browser loads the [checked-in recipe data](../../data/professions/leatherworking.json). Each entry uses the recipe's spell ID and includes its output, ingredient IDs and quantities, skill thresholds, patterns, and available sources. A static checkout or GitHub Pages serves the catalog without an API key or build step.
